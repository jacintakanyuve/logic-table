Построение логического выражения по заданной таблице истинности

В предыдущих уроках ты научился по готовой логической формуле строить таблицу истинности. Сегодня мы решим обратную задачу: научимся по заданной таблице истинности восстанавливать логическое выражение.

Этот навык лежит в основе проектирования цифровых микросхем процессоров и регулярно встречается в заданиях ОГЭ и ЕГЭ по информатике.

Обозначения, используемые в уроке:
• ¬A — инверсия (логическое НЕ)
• A ∧ B — конъюнкция (логическое И)
• A ∨ B — дизъюнкция (логическое ИЛИ)
Модуль 1 • Рекомендуемое время: 10 минут

1. Главный секрет конъюнкции

Если логическая функция зависит от n переменных, то её полная таблица истинности содержит ровно 2n строк (например, для 2 переменных — 4 строки, для 3 переменных — 8 строк).

Вспомним главное свойство конъюнкции (логического И): она равна 1 тогда и только тогда, когда все входящие в неё множители равны 1.

Правило кодирования одной строки таблицы:
Чтобы построить конъюнкцию всех переменных, которая принимает значение 1 только на одной конкретной строке (и 0 на всех остальных):
• Если переменная в этой строке равна 1 — записываем саму переменную (например, A).
• Если переменная в этой строке равна 0 — записываем её с отрицанием (например, ¬A).
Пример 1: набор A = 1, B = 0 Чтобы оба множителя стали единицами, A оставляем без изменения, а B инвертируем (¬0 = 1).
Конъюнкция: A ∧ ¬B
Пример 2: набор A = 0, B = 0, C = 1 Инвертируем нули (A и B), оставляем единицу (C).
Конъюнкция: ¬A ∧ ¬B ∧ C

2. Алгоритм построения выражения по единицам функции (СДНФ)

Чтобы записать логическое выражение для всей таблицы истинности, достаточно «включить» функцию в тех строках, где F = 1, и соединить их связкой ИЛИ (∨).

Пошаговый алгоритм (метод СДНФ):
Шаг 1. Выделить в таблице истинности все строки, в которых значение функции F = 1.
Шаг 2. Для каждой выделенной строки составить конъюнкцию всех переменных (если переменная равна 1 — берём её саму, если 0 — с отрицанием).
Шаг 3. Объединить все полученные конъюнкции знаками дизъюнкции ∨ (ИЛИ).

3. Особые случаи, метод по нулям и упрощение

Иногда в таблице истинности почти все значения функции равны 1, и только в одной строке стоит 0. В этом случае формула по единицам получается громоздкой, но её можно построить быстрее:

Построение по нулям (СКНФ) Берут строки, где F = 0. Внутри скобок переменные соединяют знаком ∨ (причём 0 берётся без отрицания, а 1 — с отрицанием), а скобки соединяют знаком ∧.
Упрощение выражений Построенную по таблице формулу можно сократить с помощью законов алгебры логики.
Пример: (¬A ∧ B) ∨ (A ∧ B) = (¬A ∨ A) ∧ B = 1 ∧ B = B.

4. Практикум: работа с фрагментами таблиц истинности
